## Why The Action Type Matters

Each scan action tells a different story. Inventory IQ uses that story for current counts, history, alerts, and predictions. The right action keeps the numbers useful later.

## Best Setup Pattern

1. Use Count first when an item is new or the current number is unknown.
2. Count only what is already present before new stock arrives.
3. Use Restock after Count to add newly received stock.

Example: if 3 are on the shelf and 10 arrive, Count 3 first, then Restock 10. Do not Count 13, because that hides the delivery from restock history and can make trends less useful.

## Choose The Right Action

- Count sets the current quantity when you physically know the number.
- Restock adds newly received stock.
- Takeout removes stock that left inventory.
- Transfer moves stock between storages or locations.

## Transfer Example

Use Transfer when stock moves from a back storage area to a front shelf. The total inventory does not change, but the location of the inventory does.
