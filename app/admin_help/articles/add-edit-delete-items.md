## What An Item Represents

An item is the thing Inventory IQ tracks. It can have a name, barcode, tags, quantity settings, and restock settings. Good item setup makes scanning faster and reports easier to read.

## Common Edits

- Name controls what users see while scanning and reviewing reports.
- UPCs control which barcodes match the item.
- Tags help group items for searching and review.
- Minimum and maximum quantities help identify low or high stock.
- Order size and lead time help restock planning.

## Safe Edit Pattern

1. Edit the item details.
2. Review the save confirmation.
3. Save only when the changes describe the real item.
4. Print new labels if barcode or name changes affect shelf cards.

## Delete Behavior

Deleting an item hides it after saving. Existing history remains for audit purposes, so past activity still makes sense.
