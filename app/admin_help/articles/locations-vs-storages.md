## Simple Definition

A location is a place. A storage is a countable area inside that place.

## Example

One location could have Front Shelf, Back Storage, and Overflow as storages. Inventory IQ can then show how much stock is in each storage instead of only showing one total number.

## Why It Matters

Storages make counts more useful. If the front shelf is empty but back storage still has stock, Inventory IQ can show that difference. Use Transfer when stock moves from one storage to another.

## Good Naming

Use names that people can recognize while standing in the real place. Clear names reduce wrong scans.
