## What A Prediction Means

A prediction is Inventory IQ's best estimate of future inventory need. It looks at recent scan history and current balances to estimate whether an item may run low or need restocking.

## What A Prediction Is Not

A prediction is not a promise, a purchase order, or proof that the shelf is empty. It is a planning signal. Always review current stock before ordering.

## What Makes Predictions Better

Predictions improve when scan history matches real activity. Count should be used to correct current stock. Restock should be used when new stock arrives. Takeout should be used when stock leaves inventory. Transfer should be used when stock moves between places.

## What Makes Predictions Worse

- Restock entered as Count hides real usage.
- Missing Takeout scans make usage look lower than it really is.
- Wrong Counts can make the current balance wrong.
- One-time events can make recent usage look unusual.
