## What Labels Do

Labels give people a scannable shelf card for an item. A good label reduces searching and helps users scan the item that is actually intended.

## Print Flow

1. Open **Print Labels** from the Admin Panel.
2. Search or select the items that need labels.
3. Preview the selected labels, or preview all active labels at once.
4. Print from the preview page.

## When To Reprint

Reprint labels whenever an item's name, primary UPC, or shelf placement changes. An outdated barcode on the shelf leads users to scan the wrong code, which can turn into an unknown-barcode review. See [Handling Unknown Barcodes](handling-unknown-barcodes).

## Tip

Fix item names and UPCs (see [Add, Edit, Or Delete Items](add-edit-delete-items)) before printing, so the labels match current inventory data instead of needing a second print run.
