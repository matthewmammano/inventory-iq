## What Labels Do

Labels give people a scannable shelf card for an item. A good label reduces searching and helps users scan the intended item.

## Print Flow

1. Open Print Labels.
2. Search or select the items that need labels.
3. Preview selected labels, or preview all active labels.
4. Print from the preview page.

## When To Reprint

Reprint labels when item names, primary UPCs, or shelf organization changes. If the barcode on the shelf is old, users may scan the wrong code or create unknown barcode reviews.

## Tip

Fix item names and UPCs before printing so the labels match current inventory data.
