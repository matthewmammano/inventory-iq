## What Unknown Means

An unknown barcode is a UPC that someone scanned but Inventory IQ could not match to an active item. It does not always mean the item is new. It may be a new package or alternate barcode for an existing item.

## Review Flow

1. Open New Barcodes.
2. Review the UPC and any suggestion.
3. Search for the correct existing item.
4. Link the UPC only when it should count as that item.
5. Leave it unresolved if you are not sure yet.

## Example

If a replacement package scans differently but should count as the same inventory item, link the new UPC to that item.

## Why This Matters

Correct barcode links make future scanning fast. Wrong barcode links make the wrong item open, which can damage counts and history.
