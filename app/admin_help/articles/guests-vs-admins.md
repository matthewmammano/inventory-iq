## Basic Difference

Guests are for normal scanning work. Admins are for setup, corrections, reports, and broader control.

## Guest Access

Guest scanners follow the permissions set in Admin Settings. A guest may be allowed to take out stock but not correct counts, or allowed to restock but only for certain storage directions.

## Admin Access

Admins can manage items, barcodes, labels, reports, settings, and broader scan routes. Admin access is better for correcting problems because it has fewer permission limits.

## Practical Rule

Use guest scanning for routine work. Use admin tools when the inventory setup, count, barcode, report, or permission needs review.
