## What Bulk Edit Is For

**Bulk Edit**, in the Admin Panel, is a faster way to update many items at one location in a single pass, instead of scanning each one separately. The dashboard links here directly when a stale-count recount is needed for a specific set of items.

## Good Times To Use It

1. Counting many shelf quantities during a full review.
2. Recording a delivery that includes several items at once.
3. Working through a "Not Counted Lately" tile on the dashboard. See [Understanding The Admin Dashboard](dashboard-overview).

## How To Keep History Clean

Enter only the rows that actually changed. Leave the rest blank. This keeps [History](review-inventory-history) focused on real updates instead of filling it with unchanged rows.

## When Not To Use It

Do not use Bulk Edit when only one item changed; a single scan through Stock Actions creates clearer, simpler history for one-off work. See [Admin Stock Actions Vs Guest Scans](admin-vs-guest-stock-actions).
