## What Count Does

**Count** replaces the current quantity with the number you enter. It is the correction tool for when Inventory IQ's displayed number does not match what is really on the shelf.

## Fix It In This Order

1. Go to **Stock Actions** (or scan directly as a guest) and choose the correct location and storage.
2. Scan or search for the item.
3. Choose **Count**.
4. Enter the quantity physically present right now.

## Example

If Inventory IQ says 8 but the shelf has 5, Count 5. Do not Takeout 3 unless 3 actually left inventory as a tracked use — that would make future Restock estimates think usage was higher than it really was. Count is for correcting the truth; Takeout is for recording stock leaving inventory.

## After The Fix

Open [View History](review-inventory-history) if you need to understand how the count became wrong before it happened again. The correction itself will appear there as a Count action at the time you entered it.
